## ⚡ whoami

I design and build systems at the intersection of **software engineering, workflow automation, artificial intelligence, and industrial control**.

My work spans three primary domains:

| Domain                       | Focus                                           |
| ---------------------------- | ----------------------------------------------- |
| ⚙️ **Automation**            | n8n, webhooks, APIs, AI workflows, integrations |
| 🖥️ **Software Engineering** | Next.js, MERN, Electron, REST APIs              |
| 🏭 **Industrial Automation** | Siemens PLC, HMI, TIA Portal, control systems   |

The objective is simple: **connect systems, eliminate repetitive work, and turn complex processes into reliable software.**

### Current Focus

* **Workflow Automation** — Designing and deploying production-oriented `n8n` workflows, webhooks, API integrations, and AI-assisted pipelines.
* **Full-Stack Development** — Building modern applications with `Next.js`, `React`, `Node.js`, `Express`, and `MongoDB`.
* **Desktop Applications** — Developing standalone `Electron` utilities and system-oriented applications.
* **Industrial Controls** — Working with `Siemens PLCs`, `HMIs`, and `TIA Portal` for physical automation systems.
* **AI Integration** — Connecting LLMs, APIs, automation platforms, and business processes into practical workflows.


## 🧩 engineering philosophy

> **Automate what can be automated.
> Build what cannot.
> Connect everything else.**

I approach projects from the system level rather than treating individual applications as isolated components.

Whether the system involves an API, an AI model, an automation workflow, a web application, or a physical controller, the goal is the same:

**make the system useful, reliable, and maintainable.**
